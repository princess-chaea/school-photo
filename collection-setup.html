교사용 Google 수합 도우미

링크 공유만 사용할 때는 설치하지 않아도 됩니다. 자동 수합을 원하는 교사가 본인 Google 계정에 한 번 설치합니다.

학생이 제출 버튼을 누른 완성 이미지 한 장만 교사의 Google Drive에 저장됩니다. Padlet 자동 게시를 켜면 해당 이미지의 Drive 링크를 공개하고 Padlet에 첨부합니다. 앱의 Firebase에는 학생 사진을 저장하지 않습니다.

설치 순서

  1. Google Apps Script에서 새 프로젝트를 만드세요.
  2. 도우미 코드 받기의 내용을 Code.gs에 붙여 넣으세요.
  3. 프로젝트 설정에서 편집기에 appsscript.json 매니페스트 파일 표시를 켜고 권한 설정 파일의 내용을 붙여 넣으세요.
  4. 포토부스 행사 관리에 Google 로그인하고 수합 도우미 설정용 내 UID 복사를 누르세요. Apps Script 프로젝트 설정 → 스크립트 속성에 이름 OWNER_UID, 값은 복사한 UID로 추가하세요.
  5. 배포 → 새 배포 → 웹 앱을 고르세요. 실행 사용자 나, 액세스 권한 모든 사용자로 배포하고 Drive·외부 연결 권한을 허용하세요. 학교 정책이 익명 웹 앱을 막으면 링크 공유를 사용하세요.
  6. 배포된 https://script.google.com/macros/s/…/exec 주소를 행사 설정의 수합 도우미 URL에 넣으세요.
  7. 본인 Drive 수합 폴더를 만드세요. 폴더 주소 https://drive.google.com/drive/folders/폴더ID에서 폴더ID를 넣으세요. Drive 전용 수합은 폴더를 공개하지 않아도 됩니다.
  8. Padlet 자동 게시라면 게시판 … → 개발자에서 보드 ID와 API 키를 복사하세요. URL·cURL·JS를 붙여 넣어 ID·키를 찾을 수도 있습니다. 유료 계정과 게시판 관리자 권한이 필요합니다.
  9. 저장하고 수합 연결 확인을 누른 뒤 행사를 게시하세요. 도우미가 Drive 접근과 Padlet 권한을 확인합니다.

사진과 API 키 처리

API 키는 이 교사 소유 Apps Script의 Script Properties에만 저장됩니다. 공개 행사 문서와 학생 코드에는 키를 넣지 않습니다. 전달 중 이미지는 메모리에서만 다루고, 최종 파일은 교사의 Drive에 저장합니다. 중복 제출 방지 기록은 최대 6시간 동안 캐시에만 유지합니다.

Padlet 게시 요청이 실패하거나 결과가 불확실하면 Drive에 제출본을 유지하고 학생에게 부분 완료를 알립니다. 같은 요청을 다시 눌러도 이 시간 동안 중복 게시하지 않습니다. 학교 정책으로 링크 공개가 막히면 Padlet 연결 대신 비공개 Drive 수합 또는 링크 공유를 선택하세요.

도우미 코드를 바꾸면 배포 관리 → 수정 → 새 버전으로 갱신하세요. API 키를 교체할 때는 행사 설정에서 새 키를 입력하고 연결을 다시 확인하세요.
