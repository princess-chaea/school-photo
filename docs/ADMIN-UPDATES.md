# 교사 보관함과 운영 현황

프레임 제작의 `frameFormat`은 4×6, 3×5, 5×7, 정사각형, SNS 피드, 스토리, A4, 화면용을 지원합니다. `frame-sizes.js`가 규격을 정의하며 템플릿 PNG, 업로드 배치, 최적화 메타데이터, 행사 프레임 정규화, 운영자·학생 렌더링에서 같은 값을 사용합니다. 기존 규격 없는 프레임은 4×6으로 유지합니다.

디자인 보관함은 스티커·학교 로고 탭, 공용 관리도 스티커·프레임 탭으로 나누며 현재 탭의 자산만 표시합니다.

운영 현황은 기존 지정 운영자 계정에만 마지막 탭으로 표시합니다. Firestore에서도 지정 운영자만 전체 행사와 `userDirectory`를 읽습니다. 각 목록은 문서 ID 순으로 100개씩 조회하며 더 불러오기를 지원합니다. 통계와 검색은 불러온 데이터 기준으로 표시합니다.

`userDirectory`에는 교사의 표시 이름, 인증 계정 이메일, 마지막 접속만 기록합니다. 기존 사용자는 다음 로그인부터 등록됩니다. Firebase Auth 전체 사용자 명부나 학생 계정 목록을 가져오는 기능은 아닙니다. 운영자는 활동을 비공개로 전환하거나 사용자별 새 게시를 제한할 수 있습니다. 새 게시 제한은 기존 공개 활동을 자동 중지하지 않으며 기존 활동은 별도 게시 중지로 처리합니다. 일반 사용자는 본인 게시 제한 값을 변경할 수 없습니다.

검증: 기능 테스트 21개, Firebase 권한 테스트 14개. 브라우저에서 로고 탭, 규격 가이드·PNG, 정사각형 업로드, 운영자 탭 숨김과 대시보드 조회·게시 중지 흐름을 확인합니다.
