# 글꼴·스티커·행사 편집 저장

행사 프레임 편집 우측 상단은 실제 행사 저장을 실행하는 `저장하고 닫기`입니다. 배치 초기화는 하단으로 옮기고 확인 후 실행합니다. 새 행사에 이름이 없거나 저장에 실패하면 모달을 닫지 않고 오류를 표시합니다.

학교안심폰트 공식 페이지 https://copyright.keris.or.kr/wft/fntDwnld 의 OFL 안내를 확인했습니다. 기존 케리스 배움체와 추가 밤하늘·덩덩이·엣지·포스터·보드마커 총 6개 글꼴을 제공합니다. 추가 글꼴은 공식 페이지의 원본 TTF에서 내부 이름·글리프를 유지해 WOFF2로 변환했습니다. `public/fonts/SCHOOL-FONTS-NOTICE.txt`에 원본 저작권·라이선스 정보, `OFL.txt`에 전문을 포함합니다. 런타임 외부 폰트 CDN은 사용하지 않습니다.

교사는 행사명·학교명·일정마다 글꼴을 선택하고 학생은 한마디·문구 글꼴을 선택합니다. Canvas 측정과 그리기에 같은 글꼴을 사용하고 PNG 저장 전에 사용한 글꼴 로드를 기다립니다. Firestore는 허용한 글꼴 ID만 저장합니다.

직접 작성한 고정 색상 SVG 스티커 30개를 추가했습니다. 기존 기본 이미지 4종과 함께 사용할 수 있습니다. 이전 색 변경 심볼 스티커는 선택 목록에서 제외하고 이미지 스티커의 색 변경 도구는 숨깁니다. 문구 글자색 변경은 유지합니다. 미리보기·이동·확대·회전·저장은 같은 이미지 자산을 사용합니다.

검증: 기능 24개, Firebase 권한 15개. 브라우저에서 실제 행사 저장과 교사 글꼴 보존, 학생 글꼴 로드, 프리셋 30종, 이미지 스티커의 색상 선택 숨김, PNG 다운로드를 확인했습니다.
