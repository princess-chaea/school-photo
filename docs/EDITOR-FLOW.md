# 학생 편집 동작

제작 단계는 용도·프레임 → 촬영 → 꾸미기 → 저장·공유의 4단계입니다. 꾸미기 모달에는 저장·공유 또는 저장 단계 이동 링크를 표시하지 않습니다. 돌아가기 후 전체 꾸미기 화면의 완성하기로 이동합니다.

사진·빈 영역의 클릭/더블클릭으로 모드를 바꾸지 않습니다. 사진 구도는 사진 구도 탭으로만 열고, 각 도구 탭 전환 시 진행 중인 드래그·두 손가락 제스처를 정리합니다. 스티커 탭에서는 이미지 꾸미기, 문구 탭에서는 텍스트 꾸미기만 선택·이동합니다. 필터 탭에서 캔버스를 클릭해도 요소 선택이나 구도 모드 전환이 일어나지 않습니다.

색감 필터는 10종입니다. 자연스러움(오리지널·선명하게), 색온도(따뜻하게·시원하게), 부드러움(소프트·파스텔), 필름(빈티지·세피아), 흑백(흑백·진한 흑백)으로 구분합니다. 필터 카드는 선택 사진의 미리보기이고 선택 효과는 모든 사진에 동일하게 적용됩니다. 원본 이미지, 프레임, 로고, 스티커는 변경하지 않습니다. AI나 외부 이미지 전송 없이 브라우저에서 처리합니다.

브라우저 검증: 휴대폰·데스크톱에서 자동 모드 전환 차단, 명시적 사진 구도 탭, 편집 저장 링크 부재, 10종의 서로 다른 렌더링 결과, 마지막 단계 PNG 저장을 확인합니다.

각 단계 하단에는 다음 이동을 명확히 표시합니다. 촬영 단계의 `꾸미기로`는 모든 사진이 채워지기 전에는 비활성화하고, 사진을 유지한 채 촬영으로 돌아온 경우에도 활성화됩니다. 꾸미기 단계는 `저장·공유로`로 이동합니다. `새로운 순간 담기`는 저장·공유 화면의 오른쪽 아래에 작은 보조 버튼으로만 표시하고 기존 초기화 확인을 유지합니다.

행사에 등록한 Padlet/Drive 링크 버튼은 Web Share를 호출하지 않습니다. 현재 완성 이미지의 다운로드를 이 탭에서 실행하지 않았다면 저장 안내 모달을 열고, 이미지 저장 실행 후 게시판 링크를 표시합니다. 이미 같은 완성 이미지의 다운로드를 실행했다면 링크 버튼에서 게시판을 바로 엽니다. 편집·필터·규격이 바뀌어 결과 이미지가 달라지면 다시 저장을 안내합니다. 갤러리 저장 완료 여부를 확인할 수 없으므로 UI는 다운로드 시작과 저장 위치 확인을 안내하며, 게시판을 열었다고 자동 제출 완료로 표시하지 않습니다. 일반 기기 공유 버튼은 별도로 유지합니다.
